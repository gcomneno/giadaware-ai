# Shared Learning Vocabulary

The cross-system learning vocabulary is:

```text
KNA          = Navigate
GYTE         = Prepare
VLE          = Verify
GiadaWare AI = Assist
```

For GiadaWare AI, **Assist** means providing optional semantic capabilities that process and propose while deterministic software retains validation, decision, mutation, editorial, and assessment authority.

`Assist` does not grant application authority and does not make GiadaWare AI a required stage of any learning workflow.

`Navigate → Prepare → Verify` is a mental-model shorthand for a common conceptual flow, not a mandatory runtime pipeline or dependency order. AI may assist across the system where explicitly composed.

The cross-system orientation record is maintained by GiadaWare KNA in `knowledge-navigation/shared-learning-vocabulary-v0.1.md`.

The normative GiadaWare AI rule remains:

> AI processes and proposes; software validates, decides, and executes.
